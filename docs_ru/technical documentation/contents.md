# TLSS - техническая документация

TLSS - центр сертификации (PKI) с веб-интерфейсом: выпускает серверные, клиентские
и EST-сертификаты, публикует CRL, отвечает на OCSP-запросы и умеет раскладывать
сертификаты по удалённым серверам через SSH. Всё состояние - в одной базе SQLite,
приватные ключи хранятся зашифрованными.

## Стандарты

| RFC | Где применяется |
|---|---|
| **RFC 5280** | Профиль X.509 и CRL: расширения CDP, AIA, KeyUsage, коды причин отзыва |
| **RFC 6960** | OCSP: формат запроса и ответа, подбор издателя, статусы |
| **RFC 5019** | Облегчённый профиль OCSP: обязательный `nextUpdate`, `unauthorized`, кэширование |
| **RFC 7030** | EST: `cacerts`, `simpleenroll`, `simplereenroll`, `csrattrs` |
| **RFC 9908** | Альтернативная структура `csrattrs` (включается флагом в конфиге) |
| **RFC 2986** | PKCS#10 - разбор CSR при EST-выпуске |
| **RFC 5652** | PKCS#7/CMS - контейнер ответов EST |
| **RFC 7292** | PKCS#12 - экспорт сертификата с ключом |
| **RFC 3339** | Формат времени во всех таблицах |

## Быстрый старт по коду

Точка входа - [`main.go`](../../main.go): читает конфиг, создаёт таблицы, накатывает
миграции, расшифровывает мастер-ключ, поднимает фоновые задачи и три HTTP-слушателя.

Маршруты собраны в [`routes/routes.go`](../../routes/routes.go) - четыре функции
регистрации по числу зон ответственности: основное приложение, CRL, OCSP, EST.
